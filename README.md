# alias_master
**alias_master** - это утилита для добавления alias в конфиг оболочки одной командой.

## Установка
Для установки необходимо иметь компилятор go не ниже версии 1.27.1. Выполните следующую команду:
```
go install github.com/ref4zxc/alias_master@latest
```
Бинарник устанавливается в $GOBIN, а если эта переменная не задана, то в $GOPATH/bin (по умолчанию это папка ~/go/bin), и она должна быть добавлена в $PATH. Чтобы узнать, куда у вас установилась утилита, выполните:
```
go env GOBIN GOPATH
```

## Использование
Утилита принимает два параметра: сам alias и команду, для которой создается alias. Новый alias будет работать только в новой сессии fish или после выполнения команды:
```
source ~/.config/fish/config.fish
```
### Примеры использования
```
alias_master cl "clear"
alias_master ll "ls -la"
```
#### Примечание
Команды обязательно нужно брать в кавычки, так как без них утилита примет команду не как один аргумент, а как несколько.
#### Пример ошибки
```
$ alias_master ll ls -la
usage: alias_master <alias> <command>
```

## Поддержка
На данный момент утилита создает alias только для оболочки fish (запись идет в конец файла ~/.config/fish/config.fish).

## Ограничения
- Одинарные кавычки внутри команды не экранируются
- Нет проверок на повторы (создание одного и того же alias приведет к повторной записи в конфиг) 
- Если последняя строка не заканчивается переводом строки, то запись alias приклеится к ней. 
- Перед запуском утилиты рекомендуется создать резервную копию
  ```
   cp ~/.config/fish/config.fish ~/.config/fish/config.fish.bak
  ```

## Планы
Планируется добавление поддержки для оболочек bash и zsh, а также решение ограничений утилиты.
